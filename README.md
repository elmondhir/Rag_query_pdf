# RAG Prod

This RAG service uses OpenRouter for both embeddings and answer generation. The
defaults use zero-cost models:

- Embeddings: `nvidia/nemotron-3-embed-1b:free` (2048 dimensions)
- Inference: `openrouter/free`

## Setup

1. Copy `.env.example` to `.env` and add an OpenRouter API key.
2. Start Qdrant on `http://localhost:6333`, or change `QDRANT_URL`.
3. Install and run the API:

   ```powershell
   uv sync
   uv run uvicorn main:app --reload
   ```

The default collection is `docs_nemotron_3`. This intentionally differs from
the former OpenAI-backed collection because vectors generated by different
embedding models are not compatible. Re-ingest PDFs before querying them.

The Inngest events are `rag/ingest_pdf` and `rag/query_pdf_ai`.
